E20 EVIDENCE DESK: SHAREABLE STATIC VERSION

Files:
  index.html
  items.json

Included interface features:
  Ranked contested claims
  Claim and reasoning filters
  Color-coded evidence cards
  Explicit supporting, challenging, corroborating, primary-record, and context cues
  Related-story links labeled by their reasoning relationship

Upload both files together to the root of any static website host.

GITHUB PAGES

1. Create a new public GitHub repository.
2. Extract the GitHub Pages ZIP.
3. Upload index.html, items.json, .nojekyll, and README.txt to the repository root.
4. Commit the files.
5. Open the repository's Settings.
6. Select Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Select the main branch and the root folder, then save.
9. GitHub will display the public URL after deployment finishes.

Important:
  This static edition is designed for open-link access.
  It does not provide secure password protection.
  A password written into browser-only HTML would be visible in the source.

Local preview:
  Serve this folder with a local web server, then open the shown URL.
  Opening index.html directly may prevent the browser from loading items.json.
